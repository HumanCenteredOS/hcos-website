# HCOS™ Decision Approach

Healthy systems should understand before they judge, assign responsibility fairly, and steward improvement intentionally.

## Analysis

**Why did this happen?**

Analysis examines system conditions, workflows, policies, technology, resources, human factors, evidence, and uncertainty.

## Accountability

**Who is responsible for what happens next?**

Accountability should reflect actual authority, role, available information, resources, and capacity to influence the outcome.

## Stewardship

**How should the system improve?**

Stewardship considers what should change, what should remain, what should be monitored, and what future leaders should inherit.
